# Easy Recorder

Gravador de tela simples, tudo local no navegador (nada vai pra internet). Grava em MP4 na qualidade máxima, com layouts de tela e câmera, fundo, zoom na câmera, versão celular 9:16 e vídeo de highlights pela intensidade da voz.

- `index.html`: o app pronto, arquivo único (é o que vai pro Cloudflare Pages).
- `src/`: código-fonte (HTML + módulos JS).
- `specs/`: especificação, plano e tarefas (SDD).
- `build.py`: gera o `index.html` a partir de `src/`.

Veja `DEPLOY.md` para publicar.
